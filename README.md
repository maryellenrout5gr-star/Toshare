# 长城像素志

一个按照 React Bits 动效文档气质制作的两页长城介绍网站。项目是纯静态文件，可以直接部署到 GitHub Pages。

## 文件

- `index.html`：长城概览与像素交换视觉首页
- `history.html`：历史时间线与两天游览路线
- `styles.css`：页面样式与响应式布局
- `script.js`：像素块动效与移动端菜单

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将本文件夹内的所有文件上传到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/root`，保存即可。

如果仓库名是 `great-wall-pixel-site`，发布地址通常会是：

```text
https://你的用户名.github.io/great-wall-pixel-site/
```
